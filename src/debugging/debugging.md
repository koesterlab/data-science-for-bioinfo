# Debugging

## Brain Book Buddy Boss Break: A Practical Debugging Framework for Learners

[Brain Book Buddy Boss Break: A Practical Debugging Framework for Learners](https://teaching-programming.github.io/book/C09_debugging-beyond-the-debugger.html) is a chapter in the open online book [Teaching Programming Across Disciplines](https://teaching-programming.github.io/book/).
This is a quick read, and anyone starting out with debugging any code should read through it.
But is also a great framework for experienced developers to formalize their debugging process---they will probably follow most of it in some way, but having it set out so clearly will probably help streamline their debugging practice.
And there might just be the odd nugget in there, that they might have previously missed.
