# Biology

Biology is a big field and of course we can't cover everything in one cheatsheet. So this is a quick reference guide for some of the key concepts and terms you'll encounter.

Generally you can divide biology into several fields called "omics", each with its own investigation target and key questions:

| Field | Measures | Key question |
|---|---|---|
| Genomics | DNA / genome | What genetic information is present? |
| Epigenomics | DNA modifications & chromatin | Which genes are potentially switched on/off? |
| Transcriptomics | RNA / transcripts | Which genes are expressed in a sample, and how strongly? (usually via RNA-seq) |
| Proteomics | Proteins | Which proteins are present and in what amounts? |
| Metabolomics | Small molecules / metabolites | What biochemical processes are active? |
| Metagenomics | DNA from mixed communities | What organisms and genes are present in an environmental/microbial sample? |
| Single-cell omics | Omics measurements per individual cell | How do molecular states differ between cells? |
| Spatial omics | Omics + location in tissue | Where in the tissue are particular genes/proteins/etc. found? |
| Multi-omics | Multiple omics layers together | How do DNA → RNA → protein → metabolites relate to each other? |

To understand what the different omics fields are and what they measure, you need to understand the process of transcribing DNA to RNA and then translating RNA to proteins. This process is called "protein biosynthesis".
